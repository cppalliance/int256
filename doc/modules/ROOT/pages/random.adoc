[#random]
= Boost.Random Support
:idprefix: random_

[source, c++]
----
#include <boost/int256/random.hpp>
----

Including this header specializes the traits that https://www.boost.org/doc/libs/release/libs/random/[Boost.Random] uses to reason about integer types, so that `uint256` can be used directly with the Boost.Random engines and distributions such as `boost::random::uniform_int_distribution`.
This header requires Boost.Random to be available, and is therefore not included by the umbrella header.

The following specializations are provided in namespace `boost::random::traits` for `uint256`:

[cols="1,2", options="header"]
|===
| Trait | Purpose

| `is_integral`
| Reports the type as integral.

| `is_signed`
| Reports the type as unsigned.

| `make_unsigned`, `make_unsigned_imp`
| Provide the unsigned type mapping Boost.Random uses when generating values.

| `make_unsigned_or_unbounded`, `make_unsigned_or_unbounded_imp`
| Provide the unsigned-or-unbounded type mapping Boost.Random uses.
|===

NOTE: These specializations live in `boost::random::traits`, not `boost::int256`. The header itself includes nothing from Boost: it forward declares the trait templates, so it costs nothing when Boost.Random is not in use.

An example combining Boost.Random with the library type is available xref:examples.adoc#examples_boost_math_random[on the examples page].
