[#api_macro_configuration]
=== Configuration

==== User Configuration

[cols="1,2", options="header"]
|===
| Macro | Description

| xref:config.adoc#no_int128[`BOOST_INT256_NO_BUILTIN_INT128`]
| Disables use of the compiler's built-in 128-bit type as a wide intermediate

| xref:config.adoc#no_simd[`BOOST_INT256_NO_SIMD`]
| Disables the SSE2 and AVX2 equality paths

| xref:config.adoc#disable_exceptions[`BOOST_INT256_DISABLE_EXCEPTIONS`]
| Disables exception throwing

| xref:config.adoc#enable_cuda[`BOOST_INT256_ENABLE_CUDA`]
| Enables CUDA support allowing the library type and functions to be run on both host and device

| xref:config.adoc#enable_sycl[`BOOST_INT256_ENABLE_SYCL`]
| Enables SYCL device support

| xref:config.adoc#build_module[`BOOST_INT256_BUILD_MODULE`]
| Builds the library as a pass:[C++20] named module (`import boost.int256`)
|===

==== Automatic Configuration

[cols="1,2", options="header"]
|===
| Macro | Description

| xref:config.adoc#automatic_config[`BOOST_INT256_HAS_INT128`]
| Defined if the compiler provides `pass:[__int128]`

| xref:config.adoc#automatic_config[`BOOST_INT256_ENDIAN_LITTLE_BYTE`]
| Defined to `1` on little-endian systems

| xref:config.adoc#automatic_config[`BOOST_INT256_ENDIAN_BIG_BYTE`]
| Defined to `1` on big-endian systems

| xref:config.adoc#automatic_config[`BOOST_INT256_HAS_MSVC_INT128`]
| Defined when the MSVC simulated 128-bit integer types are available

| xref:config.adoc#automatic_config[`BOOST_INT256_HAS_GPU_SUPPORT`]
| Defined when CUDA or SYCL device support is enabled

| xref:config.adoc#automatic_config[`BOOST_INT256_HAS_SPACESHIP_OPERATOR`]
| Defined when pass:[C++20] three-way comparison is available

| xref:config.adoc#automatic_config[`BOOST_INT256_HAS_FORMAT`]
| Defined when pass:[C++20] `<format>` is available

| xref:config.adoc#automatic_config[`BOOST_INT256_HAS_FMT_FORMAT`]
| Defined when the pass:[{fmt}] library is available

| xref:config.adoc#host_device[`BOOST_INT256_HOST_DEVICE`]
| Expands to `pass:[__host__ __device__]` under NVCC, and to `SYCL_EXTERNAL` under SYCL
|===
